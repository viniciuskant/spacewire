= SpaceWire Router: Specification
This document serves as specification and knowledge base
of the SpaceWire Router.

= Clocks

== System Reference and Generation Domains
This section defines the external oscillator clock
and the PLL-generated clocks.

=== External Reference Clock
Signal name: `ref_clk`
Speed: 50MHz

Low-frequency clock oscillator that will power the clocks
through PLLs

=== Core Base Clock
Signal name: `pll_clk_core`
Speed: 50MHz

This is the clock of the router fabric and control logic.
To handle the 200Mbps rate of the SpaceWire codec, we need
at least 200MHz / 8 (we're transmitting whole bytes) = 25MHz.
However this leaves no room for wormhole routing, arbitration etc.
So we're doing 50MHz, which is still low enough to not consume too
much power, and gives us a nice margin for housekeeping.

=== High-Speed Clock
Signal name: `pll_clk_200m`
Speed: 200MHz

200MHz PLL output serving as the master timing reference for the
200Mbps serial encoding and clock dividers.

== Router Core and Host Management Domain
This section defines the routing matrix and system management clocks.

=== Switching Matrix Core
Signal name: `core_clk`
Speed: 50MHz
Origin: `pll_clk_core`

Drives the central 8-bit parallel crossbar matrix, arbitration state machines,
and FIFO read/write ports. At 50MHz on an 8-bit bus, it provides 400Mbps of
internal bandwidth per channel; double the required 200Mbps link capacity.

*Power Strategy*: Root-gated per crossbar channel via CGICs when no active
packet transfers are routed through a given path.

== Per-Port Transmitter Domain (1 Set per Port)
This section describes the clocks going into each SpaceWire port.
Each output port requires dedicated clock generation to support
dynamic speed switching from 2Mbps up to 200Mbps, alongside standard
10Mbps initialization.

=== Base Serializer Clock
Signal name: `tx_base_clk`
Speed: 200MHz
Origin: `pll_clk_200m`

High-frequency clock driving the final TX shift-register that outputs D and S.
This clock passes through the programmable clock divider to have variable frequency
or goes directly to the shift-register and we use register enable signals to divide the write frequency.

*Power Strategy*: Gated at root per-port when link is disabled.

=== Programmable Shift Clock
Signal name: `tx_bit_clk`
Speed: 2MHz - 200MHz
Origin: `tx_base_clk`

An integrated clock divider or prescaler scales `tx_base_clk` to the configured baud rate.
During initialization, `tx_bit_clk` is forced to 10MHz.

*Power Strategy*: CGICs freeze `tx_bit_clk` when the TX buffer is empty or the port is in `ErrorReset`.


== Per-Port Receiver Domain (1 Set per Port)
Because SpaceWire is self-clocked, input receivers operate on clock domains
completely independent of the rest of the router.

=== Recovered Bit Clock
Signal name: `rx_recovered_clk`
Speed: Asynchronous (matches incoming bit rate, up to 200MHz)
Origin: (Din XOR Sin)

Generated directly per-port using clock-recovery logic from Data-Strobe input.

=== Deserialized Character Clock
Signal name: `rx_deserialized_clk`
Speed: 1/8th of the incoming bit rate (25MHz at 200MHz; 1.25MHz at 10MHz)
Origin: 1:8 deserializer

Generated by the 1:8 deserializer to load complete bytes into the RX asynchronous FIFO.
